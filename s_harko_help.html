S_Harko: Complete Technical Reference Manual

Program Name: S_Harko (derived from Swarm Harker)[cite: 1] • Core Architecture: Asynchronous FFT Patterson Engine + WebGPU Parallel Particle Swarm Optimization • Symmetry Database: 230 Space Groups (cctbx_space_groups_all_settings_v6.json)

1. Theoretical Background & The Phase Problem

In X-ray crystallographic analyses, experimentally measured diffraction intensities $I(h,k,l)$ are directly proportional to the squared structure factor magnitudes $|F(\mathbf{h})|^2$. However, phase information $\phi(\mathbf{h})$ is inherently lost during measurement. S_Harko bypasses the direct phase requirement by synthesizing the 3D Patterson function, which represents the real-space autocorrelation of crystal electron density:

$$ P(\mathbf{u}) = \frac{1}{V} \sum_{\mathbf{h}} |F_{\mathbf{h}}|^2 e^{2\pi i \mathbf{h}\cdot\mathbf{u}} = \frac{1}{V} \sum_{\mathbf{h}} |F_{\mathbf{h}}|^2 \cos(2\pi \mathbf{h}\cdot\mathbf{u}) $$

where $\mathbf{u} = (u,v,w)$ are fractional Patterson coordinates and $V$ represents the real-space unit cell volume[cite: 2].

Physical Properties of the Patterson Map

  • Interatomic Vector Representation: Patterson map peaks do not directly correspond to atomic locations $\mathbf{x}_i$. Instead, each peak located at $\mathbf{u}$ represents an interatomic displacement vector $\mathbf{u}_{ij} = \mathbf{x}_i - \mathbf{x}_j$ between atoms $i$ and $j$[cite: 2].
  • Weighting Factor: Peak heights scale proportionally with the product of the atomic numbers of the interacting pair ($Z_i Z_j$). As a consequence, heavy atoms generate dominant peaks that stand out clearly against lighter organic matrices[cite: 2].
  • Origin Peak: The point at $(0,0,0)$ corresponds to all self-vectors ($\mathbf{x}_i - \mathbf{x}_i = \mathbf{0}$) with total integrated power $\sum Z_k^2$. S_Harko automatically masks a spherical volume around the origin to prevent scalar distortion in peak finding and colour map rendering[cite: 2].
  • Centrosymmetry: Regardless of whether the space group is non-centrosymmetric, the Patterson function is strictly centrosymmetric ($P(\mathbf{u}) = P(-\mathbf{u})$)[cite: 2].

Harker Sections

Symmetry elements within space groups generate interatomic vectors constrained to specialized planes or lines termed Harker sections. For a general space group operation $\mathbf{S}\mathbf{x} = \mathbf{R}\mathbf{x} + \mathbf{t}$, symmetry-equivalent atoms generate Harker vectors defined by:

$$ \mathbf{u}_H = \mathbf{x} - (\mathbf{R}\mathbf{x} + \mathbf{t}) = (\mathbf{I} - \mathbf{R})\mathbf{x} - \mathbf{t} $$

By evaluating peak maxima on these constrained planes, S_Harko extracts discrete fractional atomic coordinates directly from one-dimensional and two-dimensional searches.

Dual-Engine Strategy in S_Harko: S_Harko couples deterministic Harker Section Analysis (for fast position solving on symmetry planes) with parallel WebGPU Particle Swarm Optimization (PSO) (for global optimization over the full asymmetric unit). Both engines operate directly on the underlying high-resolution FFT Patterson map computed by S_Harko.

2.2 Web Worker Pipeline

When data files are uploaded, S_Harko triggers a background worker thread via a single CALCULATE execution message:

STAGE 1: ASYNCHRONOUS FFT PATTERSON SYNTHESIS
  ├─ Expand unique reflections across full Friedel sphere using space group symmetry operators
  ├─ Grid determination: N = next_power_of_two( max(requested_grid, 2*h_max + 1) )
  ├─ Populate complex grid array with intensity values I(h,k,l)
  ├─ Execute 3D Radix-2 Cooley-Tukey Inverse FFT
  ├─ Map normalization: P(u,v,w) = Real(FFT) / Volume
  └─ Extract metadata: d_min resolution limit, calculated peak width σ = max(0.26 * d_min, 0.7 * dx)

STAGE 2: 3D LOCAL MAXIMA PEAK DETECTION
  ├─ Generate origin mask: exclude all grid points within 1.1 Å radius of (0,0,0)
  ├─ Calculate map statistics (mean, sigma) over non-origin voxels
  ├─ Apply dynamic candidate thresholding (min + 0.15 * [max - min])
  ├─ Run 26-neighbor 3D local maximum search with periodic boundary wrapping
  └─ Sort peaks by normalized height; retain top 50 vectors

STAGE 3: HARKER SECTION DECONVOLUTION
  ├─ Load space-group-specific Harker plane/line definitions
  ├─ Match identified Patterson peaks lying on Harker planes within 1.5 grid spacing tolerances
  └─ Deconvolve analytical solver equations: x = f(u,v,w), y = f(u,v,w), z = f(u,v,w)

STAGE 4: SITE CONSOLIDATION & CLUSTERING
  ├─ Match pairs of partial sites agreeing on 2 out of 3 coordinates across different sections
  ├─ Execute hierarchical clustering with periodic distance wrapping
  └─ Return consolidated sites array with site coincidence counts

2.3 WebGPU Swarm Optimization Engine

Global structural search in S_Harko is executed by a WebGPU compute pipeline using swarm_compute.wgsl. Each workgroup handles a single candidate particle within the swarm, running 64 parallel threads that perform symmetry expansion, compute vector matches against the experimental Patterson grid, and apply anti-bump contact distance penalties.

2.4 Symmetry & Operator Resolution

S_Harko queries space group matrices from cctbx_space_groups_all_settings_v6.json. It extracts $3 \times 3$ rotation matrices $\mathbf{R}_k$ and translation vectors $\mathbf{t}_k$, ensuring that intensity expansion and atomic coordinate generation fully respect unit cell boundary constraints.

3. Data Input & Intensity Correction

3.1 File Formats

S_Harko reads ASCII data exports generated by powder diffraction profile refinement tools (such as Powder5, FullProf, TOPAS, or GSAS-II).

3.2 Intensity Classification Hierarchy

To calculate an accurate Patterson map, S_Harko requires $|F(h,k,l)|^2$ magnitudes. S_Harko automatically classifies input columns using the following priority order:

Priority Class Detected Columns Computation Rule S_Harko Processing Mode
1 (Highest) |Fo| or Fo $\text{Intensity} = |F_o|^2$ perReflection = true. Multiplicity ($m$) and $L_p$ are already removed by the refinement software.
2 I_hkl, m, Lp $\text{Intensity} = \frac{I_{hkl}}{m \cdot L_p}$ perReflection = true. Multiplicity and $L_p$ factors are explicitly divided out per line item.
3 I_hkl, 2th_corr $\text{Intensity} = \frac{I_{hkl}}{L_p(2\theta, K)}$ perReflection = false. S_Harko calculates $L_p$ internally; multiplicity is handled during orbit expansion.
4 (Fallback) I_hkl only $\text{Intensity} = I_{hkl}$ perReflection = false. Uncorrected raw areas used; a low-angle dominant intensity warning is issued.
Critical Note on Multiplicity: If perReflection is set to true, S_Harko treats input values as single-reflection $|F|^2$ values and avoids double-dividing by reflection multiplicity during symmetry expansion.

Lorentz-Polarisation ($L_p$) Formula

When S_Harko calculates $L_p$ corrections internally, it applies the following formula:

$$ L_p(2\theta) = \frac{1 + K \cos^2(2\theta)}{1 + K} \cdot \frac{1}{\sin^2\theta \cos\theta} $$

where $K$ represents the polarization ratio (default $K = 1.0$ for unpolarized radiation, or monochromator-specific values defined in the file).

4. Patterson Map Synthesis

4.1 FFT Synthesis Engine

S_Harko uses a 3D Radix-2 Fast Fourier Transform to calculate maps. Compared to direct summation algorithms ($O(N^3 \times N_{refl})$), the FFT engine ($O(N^3 \log N)$) accelerates map calculation by over 300 times on standard grid resolutions.

4.2 Grid Resolution & Anti-Aliasing

S_Harko automatically selects an anti-aliased grid size based on the highest reflection indices present in the dataset ($h_{max}, k_{max}, l_{max}$):

$$ N_{grid} = 2^{\lceil \log_2( \max(N_{requested}, \; 2 \cdot h_{max} + 1) ) \rceil} $$

If the user toggles High Resolution mode, S_Harko sets the base grid target to $128^3$. If data indices extend beyond this limit, S_Harko increases the grid size to $256^3$ to prevent spatial aliasing.

4.3 Gaussian Peak Smearing (Calculated Maps)

Idealized interatomic delta vectors generated by trial structures produce single-voxel spikes. To enable direct comparison against resolution-limited experimental maps, S_Harko convolves trial maps with an isotropic 3D Gaussian kernel:

$$ G(\mathbf{u}; \sigma) = \frac{1}{(2\pi\sigma^2)^{3/2}} \exp\left( -\frac{|\mathbf{u}|^2}{2\sigma^2} \right) $$

By default, S_Harko automatically sets the broadening width to $\sigma = 0.26 \cdot d_{min}$, matching the experimental diffraction cutoff limit.

4.4 Least-Squares Map Scaling

To scale trial maps ($P_{calc}$) to observed experimental data ($P_{obs}$), S_Harko calculates an absolute scale factor $k$ using linear least-squares over all non-origin voxels:

$$ k = \frac{\sum_{\mathbf{u} \notin \text{origin}} P_{obs}(\mathbf{u}) P_{calc}(\mathbf{u})}{\sum_{\mathbf{u} \notin \text{origin}} [P_{calc}(\mathbf{u})]^2} $$

This scale factor $k$ is automatically applied to display calculated maps ($k \cdot P_{calc}$) and compute difference maps ($P_{obs} - k \cdot P_{calc}$).

5. Peak Finding & Harker Analysis

5.1 3D Local Maxima Search

S_Harko identifies peak vectors by scanning non-masked voxels using a 26-neighbor 3D local maximum search with periodic boundary wrapping. Points exceeding 15% of the map's total dynamic range are cataloged and sorted by height.

5.2 Harker Section Deconvolution

Peaks located on Harker sections are mapped to candidate fractional atomic coordinates $(x,y,z)$ using space-group-specific analytical expressions.

5.3 Multi-Section Site Combination

Partial site positions obtained from isolated Harker sections are cross-referenced across planes. When candidate positions agree on 2 out of 3 coordinates within the defined combination tolerance (default $0.03$), S_Harko merges them into consolidated 3D atomic sites.

6. WebGPU Swarm Optimization

6.1 Particle Swarm Dynamics

S_Harko optimizes candidate atomic positions within the asymmetric unit using Particle Swarm Optimization (PSO) on the GPU. The position vector $\mathbf{X}_i$ and velocity vector $\mathbf{V}_i$ for particle $i$ update each generation according to:

$$ \mathbf{V}_i^{(t+1)} = w \mathbf{V}_i^{(t)} + c_1 r_1 \left( \mathbf{P}_{best, i} - \mathbf{X}_i^{(t)} \right) + c_2 r_2 \left( \mathbf{G}_{best} - \mathbf{X}_i^{(t)} \right) $$
$$ \mathbf{X}_i^{(t+1)} = \text{frac}\left( \mathbf{X}_i^{(t)} + \mathbf{V}_i^{(t+1)} \right) $$

where $w = 0.5$ represents inertia, $c_1 = 1.5$ is the cognitive factor, $c_2 = 1.5$ is the social component, and $r_1, r_2 \sim U(0,1)$ are random variables.

6.2 Vector Fitness & Anti-Bump Penalties

S_Harko evaluates structural fitness by calculating the atomic-number-weighted average of observed Patterson map intensities at all predicted interatomic vector positions, minus a steric collision penalty:

$$ \mathcal{F} = \frac{\sum_{m < n} 2 Z_m Z_n \cdot P_{obs}(\text{frac}(\mathbf{x}_m - \mathbf{x}_n))}{\sum_{m < n} 2 Z_m Z_n} - \mathcal{P}_{bump} $$

If any pair of symmetry-generated atoms falls closer than the threshold distance $d_{cutoff}$, S_Harko applies a heavy steric collision penalty:

$$ \mathcal{P}_{bump} = \sum_{d_{ij} < d_{cutoff}} (d_{cutoff} - d_{ij}) \cdot \max(P_{obs}) \cdot 1000 $$

6.3 Multi-Restart PSO & Hardware Safety Limits

To avoid getting trapped in local minima, S_Harko supports multi-restart searches, running fresh randomized swarms and retaining the top global result. Particle limits are dynamically capped based on the GPU device's maximum storage buffer binding limits (`maxStorageBufferBindingSize`) to prevent driver TDR timeouts.

6.4 Minimum Contact Distance Filter

S_Harko calculates pair contact cutoffs using either a user-defined fixed distance (e.g., $2.20\text{ \AA}$) or an automatic van der Waals radius sum calculation ($0.6 \times (r_i + r_j)$), enforcing an absolute physical floor of $1.20\text{ \AA}$.

7. Visualisation & Data Export

7.1 2D Patterson Slice Viewer

S_Harko displays 2D Patterson sections perpendicular to fractional axes $u, v,$ or $w$. Users can switch between Observed, Calculated, and Difference map views ($P_{obs} - k \cdot P_{calc}$). S_Harko quotes map features directly in standard deviation ($\sigma$) units above the non-origin spatial mean.

7.2 3D Unit Cell Structure Viewer

Built on Three.js, S_Harko's interactive 3D viewer renders unit cell boundaries, fractional coordinate axes, and CPK-colored atomic spheres generated across all symmetry operations. Users can adjust asymmetric unit coordinates directly in the UI table to inspect structure modifications in real time.

7.3 Export Formats

  • Crystallographic Information File (.cif): Exports refined atomic site labels, element symbols, fractional coordinates $(x,y,z)$, site occupancy factors, unit cell metrics, space group settings, and theoretical density estimates.
  • VESTA Volume Density File (.grd): Outputs 3D density grids compatible with VESTA and ChimeraX software.
  • Peak Vector List (.csv): Exports raw 3D Patterson peak positions and consolidated Harker site solutions.
  • PDF Summary Report: Generates publication-ready summary reports containing cell metadata, active map slice visualizers, peak tables, and 3D structure views.

8. Step-by-Step Workflows

8.1 Deterministic Harker Analysis

  1. Click Select Data File to upload your experimental reflection dataset.
  2. Verify space group parameters, unit cell metrics, and reflection count displays in the sidebar.
  3. S_Harko automatically calculates the 3D FFT Patterson map and extracts vector peaks.
  4. Open the Peaks tab to review peak tables, single-section Harker site solutions, and consolidated 3D sites.
  5. Adjust the Combination Tolerance slider if necessary to refine candidate site merging.

8.2 WebGPU Swarm Global Optimization

  1. Switch to the Swarm controls tab.
  2. Add the expected asymmetric unit chemical composition (element symbols and numbers of atoms).
  3. Adjust Particle count, Iterations per run, and Restarts sliders based on GPU hardware limits.
  4. Click Initialize & Run Swarm to start WebGPU global optimization.
  5. Track real-time fitness convergence on the cost chart and monitor structural updates in the 3D viewer.
  6. When the search completes, navigate to the Swarm Results tab to inspect atomic sites, edit coordinates if desired, and click Save CIF.

8.3 Combined Hybrid Resolution Workflow

For complex structures, use Harker section analysis to solve heavy atom locations first. Then, run the WebGPU Swarm engine to place remaining lighter atoms, cross-referencing final solutions against the consolidated Harker site tables.

10. Troubleshooting & Technical FAQ

10.1 Diagnostic Solutions

Symptom / Error Root Cause Resolution
"WebGPU is not supported by this browser/device" WebGPU flags are disabled or the hardware lacks modern Compute Shader support. Use a WebGPU-enabled browser (Chromium v113+, Edge, or Firefox Nightly) with updated graphics drivers.
"GPU device lost (likely a driver timeout)" Workgroup dispatches exceeded the operating system's TDR execution limit. Reduce particle counts, lower grid resolution to 64³, or optimize the number of asymmetric unit atoms.
Intensity source reads "raw" in amber The input file lacks $|F_o|$, explicit $m$ and $L_p$ columns, or $2\theta$ values. Enable the internal "Divide out Lorentz–polarisation" toggle, or re-export reflection data with explicit correction columns.
"Symmetry warning: setting not matched" The space group setting in the file header did not match standard database naming. S_Harko falls back to standard settings; verify that cell axes match the assumed setting.
